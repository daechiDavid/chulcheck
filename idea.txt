출결 자동화 프로그렘 계획

목적: 출석인정/결석에 필요한 서류 수집 자동화
방법
웹 - 학부모들이 결석과 관련한 내용을 웹애서 작성. 작성한 내용이 docs 폴더 파일 각 양식에 자동으로 채워지도록.
admin - 로컬 설치형 프로그램 활용해서 수집된 데이터로 문서 생성하기 -> 출결 관련 문서 생성 및 일괄출력

출결 설명
결석 시 작성할 서류는 type1, type2 둘로 나뉜다.
type1: 질병결석(3종류), 미인정결석, 법정감염병, 경조사, 생리결석 으로 나뉨.
type1에는 플레이스홀더로 {{1}} ~ {{7}}이 뚫려있음
각각 사유를 {{1-reason}} ~ {{7-reason}}에 삽입함.
{{1}} - 질병결석 3일 이상. 1reason은 질병명
{{2}} - 질병결석 2일 이하. 2reason은 질병명
{{3}} - 질병결석 2일 이하 가정보육, 3reason은 학부모의견
{{4}} - 미인정결석. 4-date 미인정결석 시작일 yyyy.M.d. 형식으로, 4reason은 결석 사유
{{5}} - 법정감염병, 5reason은 감염병명
{{6}} - 경조사, 6reason은 결석사유, 증빙서류 3종류 6-r1:청첩장, 6-r2:부고장, 6-r3:기타
{{7}} - 생리결석, 7reason은 학부모의견. 

type2: 출석인정결석(교외체험학습)
type2-1: 신청서, type2-2: 보고서, type2-3: 색인 목록표
다른 플레이스홀더는 이름대로 확인하면 되고, 특징적인 값만 서술
sM, Sd : 체험학습 시작 월,일
eM, ed: 체험학습 종료 월, 일
{{sName}} : 학생 이름
aName: 학부모 이름
period: 시작일~종료일(각각 날짜 포함) 종 휴일(휴업일) 제외한 날의 수(숫자만)
M, d: 신청서, 보고서를 제출하는 날짜
색인목록표 작성법
학생명, 체험학습 시작일~종료일(N일 -색인목록표에서만 period를 숫자+일 로 표시),
{{add pr}}: 기간 누적. 동일인의 체험학습 누계 필요. 예: 3일 쓰고 5일을 쓰면 첫 번째는 3, 두 번째는 8이 되는 것.
22행까지 작성이 가능함. 22행 씩 작성 후 다음 행 작성 시에는 페이지 전체를 복사 -> 새로운 페이지에 23번부터 44번, 그 다음 페이지 복사한 내용 그대로 45~66 ... 이런 식으로 작성함


기능 정리
1. 웹앱(학부모용)
사용자가 한 가지 사유 클릭 -> {{1}}~{{7}} 부분 해당하는 번호는 속이 채워진 검은 네모, 나머지는 전부 빈 네모
사유 클릭 시 사유에 맞게 내용 입력창 및 날짜선택 datepicker
학부모 서명 -> 학부모 이름 옆 인 이라는 글자 위에 겹침으로 이미지 크기 조절하여 올려놓기

웹앱 사용자 인증 방식: 학생명 + 학부모 전화번호(부, 모 2개 중 하나 일치 시 통과 방식)
로그인 화면에서 학생명, 전화번호 입력하여 인증하는 방식.
학생명+전화번호 접속 시 교사가 미리 설정해둔 학년 반 번호 값이 자동으로 입력되도록 설정.

2. 로컬앱(관리자용)
사용자가 값 입력 -> db에 데이터 저장 -> 로컬 앱에서 알림 팝업
입력한 내용 대로 type1 또는 type2 서류 작성
우상단 담임 서명 란에 자동으로 담임 서명(또는 도장) 삽입
서류 한 번에 출력하기, 개별 출력하기 기능 모두 제공
한 번에 출력하기의 경우 모든 서류를 날짜(시작일) 순서, 날짜 동일할 경우 학생의 번호 순서대로 출력, 체험학습의 경우 신청서(type2-1) -> 보고서(type2=2) 순서로 출력
